## 고친 오류
1. **2026-09-28은 평일**입니다. 추석 연휴는 9/24~27이고 대체공휴일이 없습니다. 이전 달력이 공휴일로 잘못 처리했습니다.
2. **2026-07-17 제헌절은 공휴일**입니다. GitHub 코드(`train_and_submit.py`)는 평일로 처리하고 있어 고쳐야 합니다.
3. 문학경기장 **공연 6일이 빠져 있어서 추가**했습니다 (8/29~30, 9/12~13, 10/24~25).
4. GitHub 코드의 **근거 없는 문학 행사일은 제외**했습니다: 8/28, 9/9, 9/25, 9/26 (9/9는 경기 없음, 9/25는 우천취소, 9/26은 공연 취소).
5. 문학 **시범경기 14일과 취소 경기 17일을 추가**했습니다 (KBO 공식 일정).
6. 관중 수는 K리그 공식 기록(`ev_att_basis=official`)만 믿고, 나머지는 추정치입니다.
