## 어긋날 수 있는 부분 (조치 필요)
1. **출처·라이선스·조회일 기록 (3절)**: 비어 있던 항목을 `data/external/SOURCES.md`에 추가했으나, 팀원 외부 데이터 14개와 버스·검단 입주·축제 목록은 **원본 URL·라이선스를 팀원에게 받아야** 한다. KBO 게임센터 자료의 이용약관(비상업적 이용)도 확인 필요.
2. **Probing 경계 (4-3)**: 후보를 여러 개 만들어 점수로 **고르는 것은 허용**. 다음은 경계에 있다 — (a) 블렌드 비중을 팀원 파일 Public 점수로 한 번 계산함(K), (b) 팀원 후처리 세기(명절 보정 0.5배 등)를 Public 점수를 보고 고른 이력, (c) 검바위 보정을 단계별로(시험일 → +15·16시 → +11·13시) 만들며 점수를 확인함 — 보정 내용은 모두 학습 데이터·외부 사실에서 나왔지만, 제출 무제한 상태에서 더 반복하면 문제가 된다. 앞으로 보정 세기·비중을 점수에 맞춰 바꾸지 말 것. ZIP 설명서에 각 보정의 근거(학습 데이터 분석, 출처)를 적어 둘 것.
3. **공개 공유 (6-b)**: 팀원 GitHub 저장소가 공개라면 "대회 포럼·노트북에서만 공유" 규칙에 걸릴 수 있다 → 비공개로 바꾸거나 Kaggle 포럼에 올릴 것 (이 환경에서는 저장소 상태를 확인하지 못함).
4. **재현성 (7절)**: 최종 CSV(OPT5pp_team50_fix_cancel 기반)는 팀원이 만든 블렌드·후처리·수동 취소 보정이 들어 있어, **구성원·비율·후처리 코드·시드·requirements를 팀원에게 받아야** 재현할 수 있다. 취소 보정(OKF 9/26~27, GHOSTIVAL 10/24~25)은 근거 보도를 ZIP 설명서에 적을 것.
5. **NEIS 인증키**: 대화창에 노출됐다. 규칙과 무관하지만 약관상 개인 키이므로 재발급 권장.
